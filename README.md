# rampup-media

File host, not code. Instagram and TikTok will not accept a video file — their
servers fetch it from a public URL — so RampUp's scheduled posts need the mp4s
to already live somewhere reachable. That is all this repo does.

- `v/` — the videos, served over GitHub Pages at
  `https://melchi-1234.github.io/rampup-media/v/<key>.mp4`
- Kept out of `melchi-1234/rampup` on purpose: that repo is the site and already
  carries 215MB of history. Video there would bloat every deploy.
- Generated by `~/Documents/RampUp/tools/shorts/` — see that folder and
  `~/Documents/RampUp/video/README.md`. Do not edit these files by hand.
